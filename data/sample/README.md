# Sample data

Anonymized fixtures so the project is runnable without anyone's real spending data — also the seed
for the App Store review demo instance. Generated by transforming a copy of real purchases with
`apps/api/scripts/anonymize-legacy.ts`: fake store names/CNPJs/addresses, rebuilt NFC-e access keys,
jittered amounts (totals recomputed to stay consistent), real structure and categories.

The layout mirrors the legacy prototype (`dados/{compras,transporte,doacoes}/*.json`), so the
regular import loads it as-is:

```bash
cd apps/api
DATABASE_URL=postgres://… bun run scripts/import-legacy.ts ../../data/sample
```

To regenerate from a copy of the prototype repo (owner only — the source is private):

```bash
cd apps/api
bun run scripts/anonymize-legacy.ts <path-to-prototype-repo>
```

The anonymizer is deterministic (seeded by stable keys), so re-runs produce identical output and
diffs stay reviewable. Real data NEVER lives here — it stays in the owner's Postgres instance. See
`docs/architecture.md#data--privacy`.
